Cloudflare CTO谈AI代理时代安全平民化

No Priors

Democratizing Security for the Agentic Web with Cloudflare CTO Dane Knecht

在 No Priors 这期节目里，Cloudflare CTO Dane Knecht 把 AI 安全定性为已经压到工程团队桌面上的主线任务：漏洞报告从过去每年一次 Log4j 级别的全员应急，变成现在每周都有同等级问题。未来 18 个月，多数团队的时间和超过一半的工程时间会投向安全，企业现在就该把安全预算、红队排期和修复窗口前移，而不是等下一次漏洞爆发再抢修。

AI 把攻击工具平民化了。Dane 提到，一些近期高危漏洞并非来自国家行为体，而是高中生一类的外部玩家用 agent 去打漏洞、拿 bug bounty。企业的威胁模型要假设外部 agent 会持续扫描，修复速度要按周而不是按季度计算，先收窄关键资产暴露面，再谈复杂防御。

他不认同“把重要系统全部 air gap、暂时不信互联网”的末日判断。更现实的做法是继续从城堡护城河转向 zero trust，把办公网、设备和流量分段并强认证；关键时刻行业会合作保护关键基础设施，企业要准备应急切换和收紧策略，而不是等断网后被动停摆。

这轮安全投入是过渡期，不是永久状态。AI 会扫出大量旧代码和低级但致命的错误，例如 TLS/WebPKI 体系里用单个数字“4”做密钥种子的案例。企业应让 agent 持续做红队、代码审计和密钥随机性检查，把安全默认配置固化下来；18 个月后工程时间会回落，前提是现在把能清的漏洞清掉。
