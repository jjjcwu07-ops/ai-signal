David Silver 新实验室：用经验学习赌超级智能

Training Data

David Silver and Lasse Espeholt of Ineffable Intelligence: A Superlearner for the Age of Experience

David Silver 在 2009 年博士论文里用 reinforcement learning 打 Go，第一次证明单一领域可超越人类。他现在离开 DeepMind，创办 Ineffable Intelligence，核心判断是：超级智能不会从 LLM 的人类数据路线里长出来，而会来自系统自己从经验中持续学习、发现知识。对做 AI 的人，这等于把赌注从“喂更多人类文本”换成“让系统自己生成经验并变强”。

Lasse Espeholt 是联合创始人，曾在 DeepMind 的 deep learning 团队和 Google Brain 做 GPU 上的 reinforcement learning 扩展。他加入的原因很直接：LLM 路线已经挤满人，David 认为有另一盏路灯下面没人看。David 自己的说法是，几万到几十万研究员都在做 LLM 的 pre-training、post-training 和 coding，他不想当第 100001 个。对选择研究方向的人，这意味着差异化不在把 LLM 再调一遍，而在把经验学习做成可扩展系统。

David 从 LLM 里拿走一个反常识教训：大规模预训练后的模型，能被很小数据量快速微调，行为完全改变；规模够大时，原本很慢的事会突然变快。Ineffable 这个名字来自一个判断：超级智能发现的知识可能深到人类语言说不清，所以系统不能以人类语言为中间层。另一个隐藏含义是 this approach has to work，“不能搞砸”。对产品团队，别只盯 chat demo，先看系统能不能自己产生新知识并迁移到新任务。

这家公司的进展该用什么标准看？看 reinforcement learning 能否从 Go 这类封闭游戏走到开放经验，看跨领域迁移是否出现，看算力效率是否比堆 LLM 更好。如果这条路线成立，AI 栈会多出一个不依赖人类数据的超级学习器；如果不成立，LLM 仍是默认答案。对听众，最实用的动作是把它当作高风险高回报的替代路线，跟踪 Ineffable 的早期结果，而不是等它变成另一个聊天产品。
