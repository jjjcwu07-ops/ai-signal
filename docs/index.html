JEV作者在播客里直接给Anthropic的IPO预期泼冷水：市场把“造神”当成无限估值，把“让AI治愈癌症”当成口号式承诺，这会像Marie Antoinette说“让他们吃蛋糕”一样脱离现实。对投资者来说，Anthropic的定价若建立在对AI能力的误读上，校准偏差会直接变成估值风险；对AI safety讨论来说，宏大叙事越响，越容易掩盖具体产品能力边界。

他解释RLCD早期结果不够强仍坚持投入，是因为认定LLM终将作为API子模块被软件调用，绝大多数调用面向机器消费而非人类阅读，文风、韵律不是重点，结构化枚举和高基数输出才是。做AI产品的人要立刻分开看两类调用：给人读的token和给机器调用的token；如果还只围绕聊天体验打转，就会错过机器原生调用链的真实需求。

JEV还没到目标形态，团队发布“dreamer ready”功能，是把可靠性选择权交给开发者，因为只有开发者知道下游应用需要多少稳健性。开发者应自己定义可靠性门槛，而不是等统一榜单告诉你模型能不能上生产；模型供应商该做的是给对旋钮，不是替应用方做稳定性判断。
