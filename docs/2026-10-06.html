Rauchg 说 Vercel 的 Rust 化内部争议不小：Turborepo 从 Go 迁到 Rust 虽已完成，但人类迁移成本太高，而 Go 本身已经够快、好迭代。现在他的判断变了——「对人最好」不再等于「对生意最好」，因为写代码的越来越多是 agent。他还定了条规矩：README、博客、推文这类给人看的手写，给 agent 看的内部文档才用「AI 英文」。另外他指出模型越快（如 Astra ultrafast），harness 开销占比越高。

🧭 顾问有话说

当代码与文档的主要读者从人变成 agent，技术选型与知识生产的最优解就被重写：Vercel 对 Rust 的内部争议说明，评估框架中「维护者认知负荷」的权重正被「agent 执行效率」替换。咨询公司应据此拆开交付物标准——面向客户决策层的叙事文档坚持人工撰写，面向内部流程与 agent 调用的中间产物改按机器可解析标准生产，两套标准混用会同时压低交付质量与单位人力产出。
