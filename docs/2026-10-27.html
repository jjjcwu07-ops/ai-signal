Aaron Levie 认为，大型企业的安全现状比外界想象得更糟：库、工具、基础设施、数据和代码持续膨胀，数据高度碎片化，导致企业无法实时判断自身风险状态，部分系统权限过宽，部分系统则靠"隐晦即安全"运转。他判断转机来自最近几个月才形成的能力——长时运行的 agent 配合 computer use，可以铺开扫描、调用各类安全工具、模拟多种攻击路径、读取日志并判断数据风险等级。前提是企业先把数据和基础设施整理到位，否则 agent 无从下手；这也是他对攻防天平偏向防守方保持乐观的唯一理由。

🧭 顾问有话说

企业安全预算的流向正在从"买更多工具"转向"先把数据与权限治理做干净"，因为 agent 的价值完全取决于底层数据是否可读、权限边界是否清晰。对咨询公司而言，这意味着安全类项目的前置环节，也就是技术栈现代化与数据治理，会重新成为付费入口；而 agent 驱动的渗透测试与日志审计会压缩传统人力型安全评估的溢价空间，方法论必须从交付报告转向交付可被 agent 持续消费的数据与权限基座。

OpenAI总裁谈网安与药物研发

No Priors

The Changing Physics of Cybersecurity and Drug Development with OpenAI President Greg Brockman

Greg Brockman 在 No Priors 给了一个很硬的判断：软件会越来越便宜，真正稀缺的是可靠、安全、可验证的软件，所以企业的安全支出应当远超软件支出。他的理由不是“威胁变多”这种套话，而是网络安全的“物理规则”会变：当软件生成成本下降、攻击面随模型能力变化，靠堆人审代码、事后打补丁的预算结构会失效。对 CTO 来说，采购清单要从“买功能”改成“买可验证的安全”；对安全团队来说，要提前把预算、流程和供应商评估标准重做。

OpenAI 这轮数学成果的关键，不是模型会做题，而是它开始产出可被数学界检查的新知识。Greg 说，模型已经解决过百年数学难题，OpenAI 公布了近 400 个被解决的开放问题，数学界正在从中找洞见；真正有价值的是“为什么用这个结果”“这个证明能不能给人新思路”，不是丢出一个没人看得懂的证明。对人类来说，这意味着杠杆变高：你不需要先成为数学家，才有机会用数学解决问题。

把同一套能力挪到生物学和药物研发，逻辑是一样的：药物研发不缺模型，缺的是可验证的新假设和更快排除错误方向。AI 如果能从数学证明里学会提出结构、给出可检查的推理，它就可能帮团队筛靶点、设计实验、解释失败结果；但前提是人能审、能复现、能把洞见翻译成实验。药企和 biotech 现在该做的不是再买一个“AI 平台”，而是挑一个具体环节，把 AI 产出的假设接进实验和决策流程。

Greg 的底层立场是 AGI 必须让人留在驾驶位，增强人的 agency，而不是替人做决定。这个立场落到管理上很具体：别把 AI 当黑箱外包，关键岗位要保留能判断、能验收、能追责的人；安全、数学、药物研发都一样，工具越强，人的验收标准越要硬。
