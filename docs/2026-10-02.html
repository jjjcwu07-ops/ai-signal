多 agent 系统当前的瓶颈已经从模型能力转向中间过程的信息治理：企业若无法把 agent 之间的交互收敛成可审计的摘要层，顾问就无从复核决策链，交付物的可追溯性不成立。咨询公司自建 agent 平台时应把这一过滤层当作基础设施而非界面细节来设计。
