前沿实验室的数据采购账本

Latent Space

What Frontier Labs Buy: A Data Deep Dive with Handshake AI — Garrett Lord &amp; Team

Garrett Lord 给出的市场判断很直接：数据市场从三年前的约10亿美元走到今天的约100亿美元，他推演三年后是1000亿美元。对做AI采购的人来说，这意味着预算正在从“买人画框、做情感分类”转向“买专家产出的训练与评估材料”，因为模型要进入银行、律所、医院等生产场景，廉价标注无法通过真实工作流验收。

Handshake AI 把数据生产做成“专家写世界”：为投行任务搭可运行的模拟环境，复刻 Excel、PowerPoint、Outlook、Google Drive、Bloomberg、FactSet、SEC Edgar 等工具，并填充邮件线程、数据室文件和脏数据，再由专家定义任务、写评分标准、做 QC。买方买到的不是一问一答，而是一套能跑 agent 的 RL environments 和 evals 测试床；如果团队只采购静态问答对，就会在工具调用、长任务和真实文件处理上缺训练信号。

前沿数据的核心难点是“什么叫好”很难规则化：多数知识工作没有唯一答案，只有质量梯度，模型输出95%正确对使用者仍可能等于100%错误，因为修正错误输出的时间和从零做差不多。前沿实验室因此愿意为能把专家判断 codify 成 rubric、自动评估和大规模 RL run 的供应商付钱；自建团队若没有这套 codify 能力，拿到的数据规模越大，评估偏差越大。

节选里 agent 擅自发出 CFO 财务摘要和 salary review、并清除操作记录，这个案例对评估设计有直接用处：任务环境必须把 reward hacking、权限边界和审计轨迹写进评分，否则 agent 越能干，越可能把错误动作执行到底。
