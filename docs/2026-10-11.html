播客 · Podcast

Reflection AI 端到端自研美国开放模型 Beam

No Priors

Beam: The Great American Open Model with ReflectionAI Co-Founder and CEO Misha Laskin

Reflection AI 发布首个开放权重模型 Beam，目标是把美国开放模型推到前沿，而不是再做一个只会聊天的模型。它由 Misha Laskin 与 Janus 创立，两人此前在 Google DeepMind 做 Gemini 的强化学习；这段经历决定了他们赌 RL 能把数学、编码任务做成 agent。公司已从约30人扩到约300人，搭起预训练、中训练、强化学习团队，并端到端训完 Beam。对要选基座的团队来说，这多了一个可检查、可自托管的美国开放权重选项，不必只在闭源 API 和中国开源模型之间二选一。

起初 Reflection 想基于别人的开源模型做 RL 研究，省资本、快出结果。但一年内他们发现，真正可用的开放模型大多来自中国，西方缺少能当底座的开放模型；更关键的是，RL 要规模化，预训练和 RL 必须一起控。你不在预训练阶段埋下能力，后训练很难把模型推到 agent 水平。于是他们改路线：自己端到端建开放模型，把 RL 赌注和预训练绑在一起。对做 agent 产品的公司，这解释了为什么只拿一个开源权重做后训练，常常调不出稳定生产力；基座、数据管线、RL 环境缺一块都会卡住。

Misha 说这事没有单一瓶颈，而是30件事都要做对：招到人、留住人、让团队朝同一目标划船，拿到数据，拿到算力，再把算力变成可用的训练基础设施。他在 DeepMind 时默认可用的工具，在创业公司都要自己造。团队一年从30人扩到300人，才把预训练、中训练、RL 和各支撑团队拼齐。对创业者，这意味着前沿模型不是招几个明星研究员就能追上；组织、工程栈和迭代速度会直接决定模型能不能发、发了能不能用。

安全上，Misha 的论证很直接：砍掉网络攻击能力，也会砍掉网络防御能力。今天只有闭源实验室里几百个安全研究者理解这些系统，靠他们覆盖不了所有意外长尾。他举了一个例子：一个很强的闭源模型黑进另一家公司，那家公司能用来防御的，是开放模型。Linus 定律在这里被套到安全上：足够多眼睛盯着，多数 bug 和安全漏洞会变浅。对安全团队，这意味着把防御全押在少数闭源实验室身上，出事时你没有可审计、可本地部署的模型；开放权重是防守工具，不只是发布策略。
